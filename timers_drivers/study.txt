_> timer modes in general :
    1. overflow mode : 
    _> first the overflow mode which it jsut counts from 0 to 255
    when it reaches 255 does a overflow evnt and then returns to 0 and start counting again 
        so after we set our prescaler and our system frequency
        _> there are 3 cases to each one of these events
        1. time = Overflow time (best case) 
            _> ISR happens after ovf time normaly 
        2. time > overflow time 
            _> first we calualte how many time does it have to repeat
            so we do {time / overflow time} = no of overflows 
                _> there are 2 cases : 
                1. normal number : 
                    we do counter and it inc each time it reach the overflow 
                    and we do counter++ till we reach the specifcied number 
                    remeber : dont forget to resst the counter =0 again to repeat it 
                2. fraction number : 
                    we set a preload value so the counter start from a specifc number
                    but we increase its overflow times so it counts the correct number of times
                    to calualte it : (y is the rest of the fraction)
                        (1-0.y) * 2^n  
        3. time < overflow time 
            _> like the previous action we calualte it and it must be fraction
            insted of makeing counter = 0 each time we just set the timer register to preload value
            and each time its called it just starts from the preload value insted of 0 till it raech 
            overflow then it excutes the code then repeates

PWM mode : (pulse width modulation)
    _> what is pwm ? 
    pwm is a mode in timer to allow us to control the intensty of voltage we output insted of 0V or 5V
    it outputs a value in a from of a signal that we control the width of each pulse 
    some conecpts to understand : 
        1. perodic time : the time of 1 cycle 
        2. frequency : no of pusles in 1 sec
        3. on time : time where the pulse is high
        4. off time : time where the pulse is low 
        5. duty cycle : ratio between on time and perodic time (dont forget to * 100 )
        6. amplitude : maximum volt when signal is high
        7. V_rms : amplitude *  root(duty cycle)
    pwm in embeded : 
        1. communcation : you can have 2 MCUs talking to each other where the 
            first mcu send the pulse through the pwm and the 2nd mcu recives it from the ICU (input capture unit) ((read input signal))
            where both mcus aggre on some rules where if you recive frequency x and duty cycle y then in the 2nd mcu do something
        2. RMS : by controling the duty cycle now we can control the value of RMS the is outputed form the MCU
    how to generate PWM
        _> using software 
            1. using delay :
                for ex do motor_on() then delay(time_on) then motor_off() then delay(time_off)
            2. using normal/ctc :
                if we put a compare value in the compare register : 2 flags are rissen
                and in the isr overflow we can call it each 10uS and we do a counter till we reach our specifed numbers
        _> using hardware :
            our timer already has a hardware circuit to control the output value 
            first : fast pwm (normal mode)
